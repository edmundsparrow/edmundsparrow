## Sovereign Architecture & Particles

> I don't build for the stadium. I build for the life raft.

My code may be dirty because the infrastructure is honest.  
The security hardening, UX polish, and production wrapping can come later.  
The mechanics come first.

I prioritize **lightweight persistence**, **local-first sovereign state**, and an **offline-first reality**.  
You won't find bloated frameworks or enterprise ceremony here.  
You will find proof-of-concept mechanics for a future where technology is a tool of agency, not a luxury tax.

This is infrastructure designed to be **understood, repaired, forked, and repurposed** by builders operating under real-world constraints — unstable connectivity, low-resource hardware, limited tooling, and environments where sovereignty matters more than polish.

## Gnoke Ecosystem

A collection of offline-capable web tools built for real operators in real conditions.

| Project | What it does |
|---|---|
| [Gnoke Station](https://github.com/edmundsparrow/gnokestation) | Ultra-lightweight web desktop environment |
| [Gnoke Gasap](https://github.com/edmundsparrow/gnoke-gasap) | Gas sales tracking, inventory, and daily record management |
| [Gnoke Database](https://github.com/edmundsparrow/gnoke-database) | Self-hosted Firebase alternative. SQLite + PHP. Zero dependencies. |
| [Gnoke OBD2](https://github.com/edmundsparrow/Gnoke-OBD2) | Professional OBD-II vehicle diagnostic platform |
| Gnoke Library | Simple library record management |

All tools are built to run without a server. No vendor lock-in. No subscription. Just a browser.
